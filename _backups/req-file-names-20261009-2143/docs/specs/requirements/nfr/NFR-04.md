# NFR-04 · Nenhum conteúdo persistido; localStorage só para as chaves (BYOK)

## pt-BR

**NFR04 [Data Storage BYOK]:** Nenhum dado de sessão do conteúdo HTML/MD colado será persistido. O uso de `localStorage` é ESTRITAMENTE reservado para salvar as Chaves de API de terceiros (BYOK) inseridas pelo usuário nas configurações, garantindo anonimato global.

## en

**No content persisted; localStorage only for the keys (BYOK)**

**NFR04 [BYOK Data Storage]:** No session data from the pasted HTML/MD content will be persisted. The use of `localStorage` is STRICTLY reserved for saving the third-party API keys (BYOK) entered by the user in the settings, ensuring global anonymity.
