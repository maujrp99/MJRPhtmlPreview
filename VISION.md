# MJRPhtmlPreview

## Core Objective
A frictionless tool to load or paste HTML/Markdown, preview it instantly, make quick text edits visually, and save it to Google Drive or a local Obsidian vault in one click.

## The Vibe
Minimal Dark — dark background (#0d1117), monospace typography (JetBrains Mono), cyan/green accents (#58a6ff / #3fb950). Developer tool aesthetic — clean, fast, zero clutter.

## User Empathy
When working with AI tools (Cowork, Claude, ChatGPT), you constantly generate HTML outputs but have no quick way to preview them, make small corrections, and save them in an organized way. Copy-pasting into files manually is tedious. Hunting for a typo in raw HTML when you can see it right there in the preview is frustrating. This tool eliminates that friction: load → see → tweak → save.

## Design DNA
Think GitHub's dark mode meets a code playground (CodePen/JSFiddle) but stripped to the essentials. No accounts, no complexity — just load, preview, tweak, save. The preview is not just a viewer — it's a lightweight editing surface where you can select any text and fix it in place.
