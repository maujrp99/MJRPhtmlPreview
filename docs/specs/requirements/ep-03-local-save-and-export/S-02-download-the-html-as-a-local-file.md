# S-02 · Baixar o HTML como arquivo local

## pt-BR

Como desenvolvedor, eu quero fazer o download do HTML colado como um arquivo `.html` local para que eu possa salvá-lo facilmente no meu Vault do Obsidian.

**Acceptance Criteria:**
- [x] Existe um botão visível de "Download" (ou "Salvar Local").
- [x] Clicar no botão aciona o download de um arquivo chamado `preview_[timestamp].html`.
- [x] O conteúdo do arquivo baixado reflete o texto exato presente no `textarea` no momento do clique.

## en

**Download the HTML as a local file**

As a developer, I want to download the pasted HTML as a local `.html` file so that I can easily save it in my Obsidian Vault.

**Acceptance Criteria:**
- [x] There is a visible "Download" (or "Salvar Local") button.
- [x] Clicking the button triggers the download of a file named `preview_[timestamp].html`.
- [x] The content of the downloaded file reflects the exact text present in the `textarea` at the moment of the click.
